🎯 এই ল্যাবে শিখবে: ফাংশন কী, সরলরেখার সমীকরণ y = mx + c, দ্বিঘাত ফাংশনের গ্রাফ (পরাবৃত্ত), গ্রাফ সরানো ও ঘোরানো, এবং দুটি সমীকরণ গ্রাফে সমাধান।
ℹ️ এটি NCTB বইয়ের ক্রম মেনে বানানো এক্সট্রা ল্যাব। বইয়ের অধ্যায়ের PDF দিলে বইয়ের সাথে মিলিয়ে নোট ও প্রশ্ন যোগ করে দেব।

১. ফাংশন কী? ⭐⭐⭐

  • ফাংশন হলো একটা নিয়ম, যাতে প্রতিটি ইনপুট x-এর জন্য ঠিক একটি আউটপুট y পাওয়া যায়। লেখা হয় y = f(x)।
  • যেমন f(x) = 2x + 1: x = 3 দিলে y = 7। এটা একটা "যন্ত্র" যেটাতে সংখ্যা ঢোকালে নিয়ম মেনে অন্য সংখ্যা বেরোয়।
  • ডোমেন: x-এর যেসব মান বসানো যায়। রেঞ্জ: y-এর যেসব মান পাওয়া যায়। যেমন f(x) = √x-এ x ঋণাত্মক দেওয়া যায় না, তাই ডোমেন x ≥ ০।
  • উল্লম্ব রেখা পরীক্ষা: গ্রাফে যেকোনো উল্লম্ব রেখা টানলে সেটা বক্ররেখাকে একবারের বেশি না কাটলে তবেই সেটা ফাংশনের গ্রাফ।

২. সরলরেখা: y = mx + c ⭐⭐⭐

  • m = ঢাল: x এক ঘর বাড়লে y কত বাড়ে। m ধনাত্মক হলে রেখা ওপরে ওঠে, ঋণাত্মক হলে নিচে নামে, শূন্য হলে অনুভূমিক।
  • c = y-ছেদক: রেখা যেখানে y-অক্ষকে কাটে, অর্থাৎ (০, c)।
  • x-ছেদক: y = ০ বসালে x = −c ÷ m।

৩. দ্বিঘাত ফাংশন: y = ax² + bx + c ⭐⭐⭐

  • গ্রাফ পরাবৃত্ত (প্যারাবোলা)। a > ০ হলে মুখ ওপরে (হাসিমুখ), a < ০ হলে মুখ নিচে।
  • শীর্ষবিন্দু: x = −b ÷ 2a, তার y মান বসিয়ে বের হয়। এই x-এ খাড়া রেখাটি প্রতিসাম্য অক্ষ।
  • নিশ্চায়ক D = b² − 4ac: D > ০ হলে x-অক্ষকে দুই বিন্দুতে কাটে (দুটি বাস্তব মূল), D = ০ হলে একটি বিন্দুতে ছোঁয়, D < ০ হলে x-অক্ষকে কাটে না।
  • মূল (সমাধান) = যেখানে গ্রাফ x-অক্ষ কাটে, অর্থাৎ ax² + bx + c = ০ এর সমাধান।

৪. গ্রাফ সরানো ও ঘোরানো ⭐⭐

y = a · f(x − h) + k
k বাড়ালে গ্রাফ ওপরে ওঠে। h বাড়ালে গ্রাফ ডানে সরে। |a| বাড়ালে গ্রাফ সরু হয়। a ঋণাত্মক হলে গ্রাফ উল্টে যায়।

৫. দুটি সমীকরণের গ্রাফে সমাধান ⭐⭐

  • দুটি রেখা যেখানে কাটে, সেই বিন্দুর (x, y) দুই সমীকরণকেই সিদ্ধ করে। সেটাই সমীকরণ জোড়ার সমাধান।
  • ঢাল ভিন্ন হলে একটি সমাধান। ঢাল সমান কিন্তু c ভিন্ন হলে রেখা সমান্তরাল, কোনো সমাধান নেই। দুটি সমীকরণ একই রেখা হলে অসংখ্য সমাধান।

📏 ল্যাব ১: সরলরেখা y = mx + c

ঢাল m ও y-ছেদক c বদলে দেখো রেখা কীভাবে নড়ে। ক্যানভাসের ওপর মাউস নিলে (বা আঙুল রাখলে) বিন্দুর স্থানাঙ্ক দেখা যাবে।
